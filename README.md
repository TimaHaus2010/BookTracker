# Movie Library (Личная кинотека)

Приложение для учёта фильмов с фильтрацией и сохранением данных.

## Автор

[Хаустов Тимофей]

## Описание программы

Movie Library — это десктопное приложение для организации личной коллекции фильмов. Оно позволяет:

* Добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга.
* Фильтровать записи по жанру и году выпуска.
* Сохранять все данные в JSON‑файл для постоянного хранения.
* Просматривать коллекцию в удобной таблице.


## Требования для запуска

* Python 3.6 или выше.
* Библиотека `tkinter` (входит в стандартную поставку Python).
